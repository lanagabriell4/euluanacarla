Crie uma aplicação web interativa em arquivo único (HTML, Tailwind CSS, JavaScript e Chart.js) para o gerenciamento financeiro do show "Ainda Bem! - Luana canta Marisa". ### 1. Identidade Visual e Estética (baseada na arte do show): - **Cores principais:** Fundo em tons quentes de pêssego/salmão suave (`#f5d0b1` ou similar), detalhes em rosa vibrante/magenta (igual ao tom do título na arte) e elementos escuros ou dourados para contraste. - **Tipografia:** Estilo limpo, elegante e moderno, com uso opcional de letras cursivas para títulos românticos ou artísticos. - **Header / Capa:** No topo da tela inicial, exiba a arte oficial do show integrada de forma elegante (use a URL da imagem já hospedada no Netlify ou uma tag flexível para ela). Data do show destacada: 19.12 às 17:30. ### 2. Tela Inicial (Dashboard / Menu Principal): A tela inicial deve conter um resumo financeiro geral (Receitas Totais, Custos Totais e Lucro/Prejuízo) e 3 botões de navegação principais (com ícones e design moderno): 1. **CUSTOS** 2. **PATROCÍNIO** 3. **INGRESSOS** ### 3. Funcionalidade da aba "CUSTOS": - Formulário para adicionar novos custos com campos: **Descrição** e **Valor (R$)**. - Lista de custos cadastrados com opção de exclusão. - **Gráfico na mesma página:** Um gráfico dinâmico (usando Chart.js) comparando **Custos Totais** versus **Ganhos Totais** (Patrocínios + Ingressos vendidos) até o momento, indicando visualmente se há lucro ou prejuízo. ### 4. Funcionalidade da aba "PATROCÍNIO": - Gestão de cotas de patrocínio com 3 categorias fixas: - **Cota Ouro:** R$ 1.000,00 (Cor correspondente no gráfico: Dourado `#d4af37`) - **Cota Prata:** R$ 700,00 (Cor correspondente no gráfico: Prateado/Cinza claro `#c0c0c0`) - **Cota Apoio:** R$ 400,00 (Cor correspondente no gráfico: Rosa vibrante `#ff2a85`) - Formulário para adicionar a marca/empresa e selecionar qual cota ela comprou. - Lista de marcas patrocinadoras cadastradas por cota. - **Gráfico na mesma página:** Um gráfico redondo (tipo rosca/doughnut) mostrando a quantidade ou valor arrecadado de cotas já preenchidas, utilizando estritamente as cores correspondentes a cada cota (ouro, prata, rosa). ### 5. Funcionalidade da aba "INGRESSOS": - Gestão de ingressos vendidos (capacidade máxima de até 100 ingressos). - Campo para definir o preço unitário do ingresso e registrar a quantidade de ingressos vendidos (ou marcar nomes/compradores até atingir o limite de 100). - O valor total arrecadado com ingressos deve atualizar automaticamente o cálculo de ganhos na aba de Custos/Dashboard geral em tempo real. ### 6. Requisitos Técnicos: - Código limpo, responsivo para celulares e computadores, utilizando Tailwind CSS via CDN. - Uso de Chart.js via CDN para os gráficos. - Salvar todos os dados localmente (`localStorage`) para que as informações não se percam ao atualizar a página. - Retorne o código completo pronto para uso.
